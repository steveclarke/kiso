## Layout

| Component | Description |
|-----------|-------------|
| [App](/components/app) | Root application wrapper with background and text color defaults |
| [AspectRatio](/components/aspect_ratio) | Constrains content to a specified aspect ratio |
| [Card](/components/card) | Container for grouping related content with header, content, and footer sections |
| [Container](/components/container) | Centered content wrapper with responsive max-width |
| [DashboardGroup](/components/dashboard_group) | Full-screen dashboard shell with sidebar, navbar, and panel |
| [Empty](/components/empty) | Centered placeholder for empty content areas |
| [Footer](/components/footer) | Semantic footer element |
| [Header](/components/header) | Sticky header with backdrop blur |
| [Main](/components/main) | Semantic main element that fills remaining space |
| [Page](/components/page) | Grid layout with optional left and right sidebar slots |
| [Separator](/components/separator) | Visual divider between content sections |
| [Skeleton](/components/skeleton) | Loading placeholder with pulse animation |
| [Spinner](/components/spinner) | Spinning loading indicator |
| [Stats Card](/components/stats_card) | Dashboard metric card for displaying KPIs |
| [Table](/components/table) | Data table with semantic HTML elements |

## Elements

| Component | Description |
|-----------|-------------|
| [Alert](/components/alert) | Contextual feedback message with optional icon, title, and description |
| [Avatar](/components/avatar) | User or entity image with fallback initials and auto-contrast text |
| [Badge](/components/badge) | Displays a small label for status, category, or count |
| [Button](/components/button) | Interactive element that triggers an action or navigates to a URL |
| [ColorModeButton](/components/color_mode_button) | Light/dark mode toggle button |
| [ColorModeSelect](/components/color_mode_select) | Three-way light/dark/system mode selector |
| [Kbd](/components/kbd) | Displays a keyboard key or shortcut inline |
| [Toggle](/components/toggle) | Two-state button that can be toggled on or off |
| [ToggleGroup](/components/toggle_group) | Group of toggle buttons with single or multiple selection |
| [Tooltip](/components/tooltip) | Floating label that appears on hover or focus |

## Navigation

| Component | Description |
|-----------|-------------|
| [Breadcrumb](/components/breadcrumb) | Navigation trail showing the current page's location in the hierarchy |

| [Dialog](/components/dialog) | Modal dialog with backdrop, focus trapping, and Escape-to-close |
| [Dropdown Menu](/components/dropdown_menu) | Menu of actions or functions triggered by a button |
| [Nav](/components/nav) | Sidebar navigation with items and collapsible sections |

## Overlay

| Component | Description |
|-----------|-------------|
| [AlertDialog](/components/alert_dialog) | Non-dismissible confirmation dialog for destructive actions |
